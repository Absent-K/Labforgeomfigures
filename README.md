# Labforgeomfigures
Данный проект будет посвещён обработке геометрических фигур, а именно: поиск площадей, периметров и прочего
Проект написан студентами НГТУ группы АБс-524 1-го курса на языке программирования C++

This project will focus on the processing of geometric shapes, namely: finding areas, perimeters, and contours
The project was written by NSTU students of the ABS-524 group of 1st year students in the C++ programming language
